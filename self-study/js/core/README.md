# JavaScript Foundations: Practice Tasks

Репозиторий содержит решения практических задач по начальному блоку JavaScript (ES6+).

## Структурный обзор

* **Файл 1 (Блок 1):** Переменные, базовые типы и приведение типов (`const`/`let`, template literals, `typeof`, `===`).
* **Файл 2 (Блок 2):** Операторы ветвления, циклы и работа со строками (`if-else`, `FizzBuzz`, палиндромы, truncation).
* **Файл 3 (Блок 3):** Функции, Стрелочные функции и ES6+ синтаксис (дефолтные параметры, `rest/spread`, деструктуризация).
* **Файл 4 (Блок 4):** Массивы и методы высокого порядка (`map`, `filter`, `reduce`, группировки).
* **Файл 5 (Блок 5):** Объекты, Замыкания и Контекст (`closures`, `this`, `bind`, deep copy).
* **Файл 6 (Блок 6):** ООП и Прототипы в JavaScript.
